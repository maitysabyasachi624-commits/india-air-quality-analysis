# 🌫️ India Air Quality Trends & Pollutant Analysis (2015–2023)

## 📌 Project Overview
An interactive Power BI analytics project exploring historical Air Quality Index (AQI) patterns, seasonal spikes, and dominant pollutant drivers across major Indian cities from 2015 to 2023.

---

## 🛠️ Tech Stack & Tools
- **Data Storage & Querying:** SQL (Aggregations, Date transformations, Category filtering)
- **Visualization:** Microsoft Power BI (DAX measures, Seasonality trends, Custom KPIs)
- **Documentation:** Structured data dictionary and project reporting

---

## 📊 Key Highlights & Insights
- **Seasonality Spikes:** Identified pronounced AQI surges during post-monsoon and winter seasons.
- **Dominant Culprit:** Particulate matter (**PM2.5** and **PM10**) constitutes the vast majority of severe air quality episodes ($AQI > 200$), heavily outpacing gaseous pollutants ($SO_2$, $CO$, $NO_2$).
- **Multi-Pollutant Exposure:** Over 6,400 distinct poor-air days generated overlapping multi-pollutant threshold exceedances.

---

## 📂 Repository Structure
- `Clean/`: Source air quality datasets.
- `SQL/`: Extraction scripts and aggregation queries.
- `Power_BI/`: `.pbix` dashboard model, layout templates, and visual assets.
- `Docs/`: Project design documentation and methodology notes.
